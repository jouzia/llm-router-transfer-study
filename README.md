# LLM Router Transfer Study

An empirical study of lightweight lexical-feature-based LLM routing,
cross-benchmark transfer, baseline sensitivity, and generalization.

## Research status

The current results show that routing performance depends on the
evaluation benchmark and the selected fixed-model baseline.
The study does not currently claim a novel routing algorithm.
